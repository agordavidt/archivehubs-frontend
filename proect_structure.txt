ArchiveHubs — frontend project state
Goal: Social B2B networking platform (LinkedIn-style). Frontend is fully mock-driven with a real backend being built in parallel using Bun + Express + Neo4j (users/connections/posts) + DynamoDB (chat) + Redis (sessions) + S3 + Socket.io. Session-cookie auth.

Stack: Vite + vanilla ES modules + CSS custom properties. No framework. Partials loaded at runtime via data-include.

Key architectural rules
Only api.js and socket.js know whether we're running mock or real. Flip VITE_USE_MOCK=false in .env and everything points at the backend. No other file changes.

Components never fetch directly. They call api.* or emit socket events.

Components never call each other. They store.emit('event', payload) and others store.on(...).

Every HTML page uses one CSS link: /css/app.css. It @imports everything else.

Every HTML page includes /components/navbar.html via data-include.

Every page has a matching src/js/pages/<page>.js that calls mountPartials() then requireAuth() then per-component init functions.

Dark-mode and responsive rules live centrally (dark.css, responsive.css) — never inside component files.

Store events (pub/sub contract)
Event	Emitted by	Consumed by
session:ready / session:anonymous / session:expired	session.js	navbar, sidebar widgets
account:switched	session.js	navbar, feed, sidebar
post:created / post:deleted	create-post, feed	feed
comment:open / comment:created	post-card, comments	comments, feed
story:created / story:deleted	create-story	stories
connection:requested / connection:accepted / connection:rejected	connections, home-sidebar	connections, home-sidebar
message:openWith	anywhere	messaging (opens thread)
notification	anywhere	future notifications system
